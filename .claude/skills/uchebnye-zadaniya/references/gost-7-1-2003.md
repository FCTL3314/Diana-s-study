# Список литературы по ГОСТ 7.1-2003 (ВАК РБ) — образцы

Общие правила:
- Порядок: по алфавиту фамилий авторов / заглавий; сначала источники на кириллице, затем на латинице.
- Разделители: ` / ` перед сведениями об ответственности, ` – ` (тире с пробелами) между областями, ` : ` перед подзаголовком и издательством, ` ; ` между разными группами ответственности.
- Общее количество страниц: `– 256 с.`; для статьи — диапазон: `– С. 12–18.`
- Для электронных ресурсов: `[Электронный ресурс]`, `– Режим доступа: URL. – Дата доступа: ДД.ММ.ГГГГ.`
