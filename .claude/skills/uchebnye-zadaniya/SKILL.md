## Порядок работы (как в режиме Cowork: довести до готового файла)

1. **Разобрать запрос.** Выписать все задания по пунктам. Если что-то неясно (формулировка, объём, дисциплина, нужен ли титульный лист, есть ли методичка или требования преподавателя) — **обязательно задать вопросы через AskUserQuestion до начала работы**. Не угадывать.
2. **Литература (смешанный режим).**
   - Сначала использовать источники, которые дала Диана (список, PDF, фото страниц, ссылки). Прочитать их.
   - Если их нет или не хватает — найти **реальные** источники через WebSearch/WebFetch: учебники и пособия по логопедии и специальной педагогике (Волкова, Филичева, Чиркина, Жукова, Мастюкова, Лопатина, Ткаченко, Лалаева, Визель, белорусские авторы — Шеремет, Лещинская, Кисель, Казак и др.), нормативные документы Республики Беларусь (Кодекс об образовании, учебная программа дошкольного образования), статьи из научных журналов (КиберЛенинка, eLibrary, репозиторий БГПУ — elib.bspu.by).
   - **Никогда не выдумывать** источники, авторов, годы, издательства и страницы. Каждый источник в списке должен существовать.
   - Обычно 5–10 источников, желательно не старше 10–15 лет (классика допустима).
3. **Выполнить задания** на русском языке, подробно и академично: научный стиль, определения понятий со ссылкой на автора, классификации, таблицы там, где их просит задание или где они уместны, практические примеры из работы логопеда с дошкольниками. Каждое задание опирается на литературу.
4. **Ссылки в тексте** — по ГОСТу, в квадратных скобках: номер источника из списка и страница — `[1, с. 55]`, несколько источников — `[2, с. 14; 5, с. 103]`, ссылка на весь источник без страницы — `[3]`.
   - Страницу указывать, только если она реально известна (из присланного текста, PDF или найденного фрагмента с пагинацией). Если страницу проверить нельзя — ставить ссылку без страницы или спросить Диану, и в итоговом сообщении перечислить такие места.
5. **Список литературы** в конце документа под заголовком «Список использованных источников» — по **ГОСТ 7.1-2003** (требования ВАК РБ). Нумерация арабскими цифрами, порядок — по алфавиту (сначала кириллица, потом латиница), номера совпадают со ссылками в тексте. Образцы — в `references/gost-7-1-2003.md`.
6. **Собрать Word-файл** скриптом `scripts/build_docx.py` (см. ниже).
7. **Отдать файл**: SendUserFile с `display: "attach"`. Кратко написать, что сделано, какие источники найдены самостоятельно и где страницы не удалось проверить.

## Где хранить файлы — важно

Репозиторий используется **только для чтения** (здесь лежит этот скил). Задания **не коммитить и не пушить**. Черновик и итоговый .docx создавать в scratchpad-директории сессии (или в `/tmp`, если её нет), а не в репозитории.

## Оформление Word

- Шрифт Times New Roman 14 пт (весь документ, включая таблицы — допустимо 12 пт в таблицах).
- Поля «узкие»: 1,27 см со всех сторон.
- Межстрочный интервал одинарный (1,0), интервалы до/после абзаца 0.
- Выравнивание основного текста по ширине.
- Нумерация страниц внизу по центру (на титульном листе не показывать).
- Заголовок к каждому заданию: «Задание 1. <формулировка>» — полужирный.
- Титульный лист — **только если Диана об этом попросила или это указано в задании**.

## Как собрать .docx

Написать содержимое в Markdown-файл (в scratchpad) и запустить:

```bash
python3 .claude/skills/uchebnye-zadaniya/scripts/build_docx.py input.md output.docx [--title-page title.json]
```

Если нет python-docx: `pip install python-docx`.

Поддерживаемая разметка `input.md`:

- `# Текст` — заголовок документа (полужирный, по центру)
- `## Задание 1. ...` — заголовок задания (полужирный)
- `### Текст` — подзаголовок (полужирный курсив)
- обычные абзацы; пустая строка разделяет абзацы
- `- пункт` — маркированный список; `1. пункт` — нумерованный
- `**жирный**`, `*курсив*` внутри текста
- таблицы в формате Markdown (`| a | b |` + строка `|---|---|`)
- `## Список использованных источников` + нумерованный список `1. ...` — список литературы
- строка `\pagebreak` — разрыв страницы

`title.json` для титульного листа (поля, которых нет, — пропускаются):

```json
{
  "kafedra": "Кафедра логопедии",
  "work_type": "ПРАКТИЧЕСКАЯ РАБОТА",
  "discipline": "по дисциплине «...»",
  "topic": "на тему: «...»",
  "teacher": "Проверил(а): должность, ФИО"
}
```

Остальные данные титульного листа (университет, институт, ФИО, курс, группа, город, год) скрипт подставляет сам.

После сборки проверить результат: открыть .docx через python-docx или `pandoc output.docx -t plain | head -80` и убедиться, что заголовки, ссылки и список литературы на месте.
